# Current conditions test card

Default builds do not render the card or request any weather data. A local/approved staging build can opt in at build time with `NEXT_PUBLIC_HDMS_MAP_WEATHER_TEST=1`. Explicit action is required per request. The selected map point is used when present; otherwise the Pattani map center is used. GPS is requested only on a clearly labeled action, approximate coordinates (2 decimals) are sent without a referrer or credentials, and no position is persisted by HDMS. The prototype does not poll. Open-Meteo’s current field represents a model estimate for a recent time, not a station reading. The API timestamp is shown in Asia/Bangkok, not a claim about model initialization or time of a field observation. Observations from [TMD Weather3HoursBySynop](https://data.tmd.go.th/api/doc/reference/Weather3HoursBySynop.pdf) are a separate station product and are not fetched by this prototype.

Before any public enablement, check the latest [Open-Meteo terms](https://open-meteo.com/en/terms) and confirm this institutional use and expected volume qualify or arrange the proper service tier. CC BY 4.0 [data licensing](https://open-meteo.com/en/licence) permits attributed reuse separately from the free API's non-commercial eligibility, published limits, and lack of uptime guarantee. Keep the model label and timestamp; it is not observed rainfall or an official warning. Do not add keys to client code. A production gate should also cover quotas, resilience, and privacy notices.

Fixture verification: `NEXT_PUBLIC_HDMS_MAP_WEATHER_TEST=1 PLAYWRIGHT_STATIC=1 npm run test:e2e:local -- tests/e2e/map-current-weather.spec.ts`. Set `NEXT_PUBLIC_HDMS_MAP_WEATHER_TEST_GPS=1` as well to exercise staging GPS. Repeat with all three flags unset to verify the default build.

Fixture responses are intercepted by Playwright and explicitly identified as **ข้อมูลจำลอง**. Non-fixture responses are labeled **ข้อมูลจากแบบจำลอง**. A one-shot Pattani request with the GitHub Pages Origin header returned HTTP 200 and Access-Control-Allow-Origin: *. Another attempt timed out in Chromium through the test proxy; connectivity/reliability in Thailand is not established. Under the free service privacy terms, provider logs may include sent coordinates and are retained up to 90 days. Keep the location disclosure and have HDMS privacy owners approve this before public enablement. The [offline rain/storm animation](prototypes/weather-animation/README.md) is independent and not mounted in HDMS.

## Conservative public candidate (off unless explicitly enabled)

- `NEXT_PUBLIC_HDMS_MAP_WEATHER_PUBLIC=1` is an independent, build-time public enable switch. Only the fixed public Pattani reference point (6.82°N, 101.25°E), not the map selection or browser location, is used, after pressing **ดูสภาพอากาศ**. No polling, analytics or position persistence is added. Browser requests still connect to the provider and can reveal ordinary network metadata such as the IP address.
- The staging-only GPS exercise requires both `NEXT_PUBLIC_HDMS_MAP_WEATHER_TEST=1` and `NEXT_PUBLIC_HDMS_MAP_WEATHER_TEST_GPS=1`. The GPS option stays unavailable in public mode even if all flags are set. Default builds and public mode never request GPS for this card. The previous Open-Meteo assessment covers the two-decimal coordinates only in that staging exercise.
- Provider terms cite non-profit websites without subscriptions/advertising as eligible examples, but do not explicitly call out deployed government operational services. Public use is defensible only if HDMS confirms its own ad-free/non-subscription/non-commercial use, forecast is informational (not a warning or travel recommendation), expected aggregate usage satisfies provider limits, and a browser on the intended public network can access it. Keep public flag off until those checks pass; disabling the flag and rebuilding rolls the feature back independently.
- Opening the card does not send a request. The model valid time is not model initialization or a field observation. Data more than two hours old or more than ten minutes future, and provider/network failures, are not displayed as current conditions and do not replace traffic/official warnings.
- For candidate browser tests set `NEXT_PUBLIC_HDMS_MAP_WEATHER_PUBLIC=1` instead of the staging flag. The separate offline rain/storm demo does not fetch or publish real radar or offshore tracks.
