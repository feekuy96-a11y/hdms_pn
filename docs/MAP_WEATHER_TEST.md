# Current conditions test card

Default builds do not render the card or request any weather data. A local/approved staging build can opt in at build time with `NEXT_PUBLIC_HDMS_MAP_WEATHER_TEST=1`. Explicit action is required per request. The selected map point is used when present; otherwise the Pattani map center is used. GPS is requested only on a clearly labeled action, approximate coordinates (2 decimals) are sent without a referrer or credentials, and no position is persisted by HDMS. The prototype does not poll. Open-Meteo’s current field represents a model estimate for a recent time, not a station reading. The API timestamp is shown in Asia/Bangkok, not a claim about model initialization or time of a field observation. Observations from [TMD Weather3HoursBySynop](https://data.tmd.go.th/api/doc/reference/Weather3HoursBySynop.pdf) are a separate station product and are not fetched by this prototype.

Before any public enablement, check the latest [Open-Meteo terms](https://open-meteo.com/en/terms) and confirm this institutional use and expected volume qualify or arrange the proper service tier. CC BY 4.0 [data licensing](https://open-meteo.com/en/licence) permits attributed reuse separately from the free API's non-commercial eligibility, published limits, and lack of uptime guarantee. Keep the model label and timestamp; it is not observed rainfall or an official warning. Do not add keys to client code. A production gate should also cover quotas, resilience, and privacy notices.

Fixture verification: `NEXT_PUBLIC_HDMS_MAP_WEATHER_TEST=1 PLAYWRIGHT_STATIC=1 npm run test:e2e:local -- tests/e2e/map-current-weather.spec.ts`. Repeat without the weather flag to verify the default build.

Fixture responses are intercepted by Playwright and explicitly identified as **ข้อมูลจำลอง**. Non-fixture responses are labeled **ข้อมูลจากแบบจำลอง**. An environment check for the non-sensitive Pattani point timed out at the upstream proxy (HTTP 503); live provider connectivity in the intended browser remains unverified. The [offline rain/storm animation](prototypes/weather-animation/README.md) is independent and not mounted in HDMS.
