# โครงสร้างโมดูลแผนที่ HDMS

อ่านหน้านี้ก่อนแก้แผนที่หน้าประชาชนหรือหน้าแอดมิน เทียบสถานะจริงกับ branch ปัจจุบัน แล้วเปิดเฉพาะไฟล์ที่ตรงงานตามตาราง

```text
app/page.tsx (ประชาชน) ─┐
                        ├─ SharedOperationalMap → LongdoGisMap
app/admin/page.tsx ─────┘   ├─ MapLegendOverlay / MapStatusRow
                            ├─ useLongdoRouteLayers / longdo-map-popups
                            └─ useSharedGisFocus / useLongdoFocusLayer / GisFocusModeBar
```

เส้นทางทั้งสองใช้ [จุดเข้าเดียว](../../components/map/SharedOperationalMap.tsx) รวมสถานะโหลดและแผนที่หลัก ไม่คัดลอกเครื่องมือ ป๊อปอัพ หรือวิธีวาดเส้นไปสร้างใหม่ในแต่ละหน้า หน้าเว็บจัดหาเฉพาะข้อมูล การอนุญาตของปุ่ม และ callback ของงานในหน้านั้น

| อยากแก้อะไร | เปิดคู่มือนี้ | แก้ที่ต้นทาง |
| --- | --- | --- |
| ซูม ตำแหน่ง เปลี่ยนแผนที่ฐาน เลเยอร์ และคำอธิบายสัญลักษณ์ | [เครื่องมือและเลเยอร์](controls.md) | `MapLegendOverlay.tsx`, `LongdoGisMap.tsx`, `useAdministrativeBoundaries.ts` |
| รายละเอียดหมุด A/B เส้น และปุ่มในป๊อปอัพ | [ป๊อปอัพ](popups.md) | `longdo-map-popups.ts`, `useLongdoRouteLayers.ts` |
| ข้อความ ไอคอน สี และการ์ดสรุปสถานะบนแผนที่ | [สถานะ](status.md) | `MapStatusRow.tsx`, `lib/traffic-presentation.ts` |
| เข้า/ออกโฟกัส กล้อง แนวเส้น ปุ่มขาไป/กลับ | [โหมดโฟกัส](focus.md) | `useSharedGisFocus.ts`, `useLongdoFocusLayer.ts`, `GisFocusModeBar.tsx` |

**เกณฑ์ทดสอบ:** ให้หน้าประชาชนแบกรายละเอียดพฤติกรรมที่ใช้ implementation เดียวกัน ส่วนทั้งสองหน้าต้องตรวจว่าต่อเข้ากับแผนที่จริงและปุ่มไม่ถูกบังทั้ง viewport ที่เสี่ยง คงเทสต์ที่ผลลัพธ์ต่างกันจริง เช่น แอดมินปักหมุด/คืนฟอร์ม ประชาชนเปิดรายละเอียด/นำทาง ป๊อปอัพหมุดน้ำท่วมของแอดมินเมื่อเปิดขอบเขตปัตตานี และโหมดออฟไลน์ตาม CI เดิม อย่าตีความว่าการใช้โมดูลเดียวแปลว่าตัด smoke test ของหน้าใดหน้าหนึ่งได้

ขอบเขตนี้คือแผนที่หลักของสองหน้า ไม่รวมหน้าตัวอย่างปิดการจราจรที่ยังรออนุมัติ ไม่เพิ่มข้อมูลหรือเปลี่ยนสิทธิ์การใช้งาน
