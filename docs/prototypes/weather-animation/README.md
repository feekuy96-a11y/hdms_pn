# HDMS อนิเมชันแผนที่อากาศ (ต้นแบบออฟไลน์)
เปิด index.html โดยตรง ไม่ต้องติดตั้งและไม่ใช้เครือข่าย ภาพและพิกัดเส้นทางพายุเป็นข้อมูลสังเคราะห์ทั้งหมด ไม่ใช่ HDMS จริง ไม่ใช่เรดาร์จริง ไม่ใช่ประกาศเตือนภัย

- เรดาร์ฝนย้อนหลัง: ภาพต่อเวลา แยกจากการคาดการณ์และสถานะถนน
- เส้นทางพายุ: เส้นทึบคือจุดวิเคราะห์ เส้นประคือคาดการณ์ มีเวลาออกประกาศและเวลาที่จุดคาดการณ์มีผล ไม่ตีความเป็นเขตเตือนภัย
- Chromium/Playwright ที่ความกว้าง 390 และ 1280 พิกเซล: เล่น/หยุด, ควบคุมเฟรมด้วยแป้นพิมพ์, เวลาประเทศไทย, ทดสอบไม่มี HTTP(S) request, ไม่มี JS error และไม่มีแนวนอนล้น

แหล่งสำหรับใส่ข้อมูลจริงในอนาคต
1. [เรดาร์ทางการ กรมอุตุนิยมวิทยา](https://instrument.tmd.go.th/radar/) และ [เรดาร์หาดใหญ่ 240 กม.](https://weather.tmd.go.th/hyi240_HQ_Loop_edit2.php) เหมาะสำหรับลิงก์ออกไปดูทันที ยังไม่พบสิทธิ์ที่ยืนยันว่า HDMS นำภาพ/ข้อมูลดังกล่าวมาจัดชุดหรือเผยแพร่ซ้ำเป็นเลเยอร์ได้ การดาวน์โหลดภาพสำเร็จไม่เท่ากับสิทธิ์เผยแพร่ ห้ามใช้ภาพที่มีแกน/เลเยอร์ซ้อนจากหน้าเว็บเป็นไทล์โดยไม่ขอ bounds/CRS/georeference ของผลิตภัณฑ์
2. [RainViewer terms](https://www.rainviewer.com/api.html) ข้อกำหนดระบุส่วนบุคคลหรือการศึกษา; FAQ ระบุชุมชนขนาดเล็กด้วย แต่ไม่รับประกันการใช้งานเว็บหน่วยงาน ต้องให้ attribution ไม่มี SLA. [Weather Maps API](https://www.rainviewer.com/api/weather-maps-api.html) ระบุเรดาร์ย้อนหลัง ~2 ชม. ช่วง 10 นาที, XYZ ไทล์ Web Mercator สูงสุด z7; time คือเวลาเฟรมรวม ไม่ใช่เวลาสแกนสถานี. หากภายหลังได้รับสิทธิ์ ให้ overzoom ต้นฉบับ z7 ไม่ร้องไทล์เกิน z7 และระบุขอบเขตข้อมูล/ข้อมูลค้างเมื่อเกิดปัญหา.
3. [JMA RSMC Tokyo](https://www.jma.go.jp/jma/jma-eng/jma-center/rsmc-hp-pub-eg/RSMC_HP.html) เป็นแหล่งเส้นทางพายุทางการสำหรับแปซิฟิกตะวันตกและทะเลจีนใต้ ไม่ใช่แหล่งครอบคลุมพายุทุกกรณีในปัตตานีหรืออ่าวเบงกอล; [หมายเหตุ JMA](https://www.jma.go.jp/jma/jma-eng/jma-center/rsmc-hp-pub-eg/advisory.html) แยกจุดวิเคราะห์ จุดคาดการณ์ วงความน่าจะเป็น; [เงื่อนไขเว็บไซต์](https://www.jma.go.jp/jma/en/copyright.html) ใช้ Public Data License 1.0 โดยทั่วไปเว้นข้อกำหนดเฉพาะ/สิทธิ์บุคคลที่สาม ต้องตรวจแหล่งข้อมูลเชิงเครื่องอ่านตัวจริงและสิทธิ์ก่อนนำมาเผยแพร่ และลิงก์ประกาศของกรมอุตุนิยมวิทยาประเทศไทยเป็นแหล่งอ้างอิงหลัก.
4. [NOAA IBTrACS](https://www.ncei.noaa.gov/products/international-best-track-archive): เหมาะแสดงตัวอย่างเส้นทางย้อนหลัง ไม่ใช่เส้นทางคาดการณ์หรือระบบเตือนภัยสด.

ตรวจความครอบคลุม 26 พ.ย. 2569: ตัวอย่างที่จุด 6.87,101.25 ได้ PNG 256x256 ที่ z7; พิกเซลกลาง coverage mask โปร่งใส (อยู่ในขอบเขตที่ provider ระบุ); ไทล์เรดาร์เฟรม 19:10 น. ตอบ HTTP 200 และมีทั้งพิกเซลโปร่งใสและทึบ; พิกเซลกลางโปร่งใส จึงไม่ควรสรุปว่าตำแหน่งนี้ไม่มีฝน ไม่มีข้อมูล หรือสถานีใดสแกนอยู่จากตัวอย่างเพียงเฟรมเดียว.
